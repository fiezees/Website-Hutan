# Proyek Website Sederhana: Eksplorasi Hutan 🌲

Proyek web edukasi bertema **Hutan** yang dibangun menggunakan murni file HTML (`index.html`) tanpa dependensi eksternal, package manager, atau konfigurasi rumit.

## 🌿 Fitur & Struktur Halaman
1. **Hero Header**: Judul dan pengantar menarik bertema kelestarian hutan dengan desain modern.
2. **Navigasi Pintas (Sticky Nav)**: Tautan cepat antar bagian halaman (`Tentang`, `Jenis`, `Manfaat`, `Flora & Fauna`, `Fakta`, `Komitmen`).
3. **Jenis-Jenis Hutan**: Kartu informasi bergambar untuk Hutan Hujan Tropis, Mangrove, Hutan Musim, dan Hutan Boreal (Taiga).
4. **Fungsi & Manfaat Hutan**: Penjelasan peran hutan sebagai penghasil oksigen, penyerap karbon, pengatur tata air, dan pencegah bencana.
5. **Flora & Fauna Ikonik**: Sorotan keanekaragaman hayati seperti Orangutan, Harimau Sumatera, dan Bunga Rafflesia.
6. **Fakta Menarik (Trivia)**: Fitur akordion interaktif menggunakan elemen native HTML `<details>` dan `<summary>`.
7. **Form Dukungan Kelestarian**: Formulir sederhana interaktif untuk menyatakan komitmen menjaga lingkungan.

## 🚀 Cara Menjalankan Proyek
1. Buka folder proyek di File Explorer.
2. Klik ganda (double-click) pada file **`index.html`**.
3. Halaman akan langsung terbuka di browser (Chrome, Edge, Firefox, dsb.) tanpa perlu server lokal.
